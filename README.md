Projeto simples desenvolvido com HTML, CSS e JavaScript que permite alternar entre os temas claro e escuro através de um botão.

📌 Sobre o projeto

O objetivo deste projeto é praticar conceitos básicos de desenvolvimento web, principalmente a manipulação de classes do CSS através do JavaScript.

Ao clicar no botão, o tema da página é alterado entre:

☀️ Tema Claro

🌙 Tema Escuro

🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript

⚙️ Como funciona

O JavaScript utiliza o método classList.toggle() para adicionar ou remover a classe responsável pelo tema escuro.

Exemplo:

document.body.classList.toggle('tema-escuro');

Quando a classe tema-escuro está presente no <body>, o CSS aplica as características do tema escuro.
